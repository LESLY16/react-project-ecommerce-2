# React E-Commerce Store

A full-featured React e-commerce store with Redux, React Router, and authentication.

## Features
- Product catalog with search and filtering
- Shopping cart with persistence
- User authentication (login/register)
- Product reviews
- Admin dashboard
- Responsive design

## Tech Stack
- React
- Redux Toolkit
- React Router v6
- JSONPlaceholder API

## Getting Started

```bash
npm install
npm start
```
